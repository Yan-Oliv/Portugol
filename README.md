# Portugol — Algoritmos (Sistemas de Informação, 1º período)

![Portugol](https://img.shields.io/badge/Portugol-111?style=flat-square) ![VisuAlg](https://img.shields.io/badge/VisuAlg-0b5394?style=flat-square) ![Acadêmico](https://img.shields.io/badge/Acadêmico-6b7280?style=flat-square)

Primeiros algoritmos do curso de **Sistemas de Informação**, escritos em Portugol (arquivos `.ALG`, executáveis no VisuAlg). Cada pasta traz o **enunciado** e a solução.

| Pasta | Conteúdo |
|---|---|
| `Market System/` | Sistema de mercado (`QUEBARATO.ALG`) e enunciado |
| `Vend System/` | Sistema de vendas (`VENDSYS.ALG`) e enunciado |
| `Viagem And Menu/` | Sistema de viagem com menu (`Viagem_Menu.ALG`) e enunciado |
| `Trabalho Final Vetores e Matrizes/` | Lista final com vetores e matrizes (`ListaFinal.ALG`) e lista de exercícios |

## Como executar

1. Instale o [VisuAlg](https://visualg3.com.br/).
2. Abra o arquivo `.ALG` desejado e execute (F9).

## O que foi praticado

Entrada e saída, estruturas condicionais e de repetição, menus, vetores e matrizes: a base de lógica que levou aos projetos seguintes.
